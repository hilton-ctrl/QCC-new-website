## WHY THIS IS THE "LEVEL 3" VERSION

The reviews say the surface product is *carpet cleaning*. Level 3 says the real product is **relief, pride, protection from judgment, and protection from bond loss**. Every beat below sells that deeper layer, not the machine:

- **Dominant Resident Emotion:** anxiety about the inspection / the smell / being judged.
- **Unique Mechanism (mandatory at this market level):** the *Tri-Active Dry-Extraction Protocol* — sold as the hero, ~75% of the copy.
- **Mechanism-of-the-Problem first** (the buried sand + wet-steam trap = "not your fault"), **then** Mechanism-of-the-Solution.
- **Emotional arc:** Recognition → Hope → Belief → Urgency.
- **Close:** Crossroads (loss aversion + future pacing) → single clear CTA.

# PART 3 — TTS NORMALISATION REFERENCE

*This is the "extract every number and character that would sound nonsensical" list you asked for. Use it as a reusable checklist whenever you push any of your sales copy through Cartesia. It's grouped so you can also apply it to the original sales letter (which is loaded with citation brackets, star emojis, strikethrough prices, and table pipes — all of which Cartesia will mangle).*

## 3.2 Extra numbers & prices in the ORIGINAL sales letter (if you reuse those assets)

| Written | Say |
|---|---|
| `$197` | one hundred and ninety-seven dollars |
| `$497` | four hundred and ninety-seven dollars |
| `$350` | three hundred and fifty dollars |
| `$850` | eight hundred and fifty dollars |
| `$185` | one hundred and eighty-five dollars |
| `$85` / `$60` / `$40` | eighty-five / sixty / forty dollars |
| `$3,200` | three thousand, two hundred dollars |
| `$4,000` | four thousand dollars |
| `110%` | one hundred and ten percent |
| `100%` | one hundred percent |
| `Bonus #1 / #2 / #3` | bonus number one / two / three |
| `24/7` | twenty-four seven |
| `up to 6 bedrooms` | up to six bedrooms |

**Rule of thumb for Cartesia:** it often reads a bare number correctly, but it is **unreliable with currency and percentages** — it will drop the word "dollars," misplace it, or read `$550` as "dollar five fifty." Spell prices and percentages out in full, every time. Put the word *dollars* **after** the number, the way you'd speak it.

## 3.3 Symbols — always convert or strip before TTS

| Symbol | Problem | Do this |
|---|---|---|
| `$` | read wrong / dropped | spell the amount, put "dollars" after |
| `%` | inconsistent | write "percent" |
| `&` | may be silent or "ampersand" | write "and" |
| `/` | read as "slash" | write "and", "or", or split the words (`Look/Feel/Smell` → "look, feel and smell") |
| `~` (tilde) | read as "tilde" or ignored | write "about" / "around" |
| `≤` `≥` `+` `=` | read literally or skipped | write "under", "over", "plus", "equals" |
| `#` | "hash" or "number sign" | write "number" (`#1` → "number one") |
| `—` (em dash) | usually a pause — **OK in Cartesia**, but overuse = choppy | keep sparingly; replace with comma if the pause feels wrong |
| `…` / `...` | sometimes read as "dot dot dot" | keep only where you want a real pause; otherwise use a period or comma |
| `-` (hyphen in `re-treat`, `dry-clean`) | fine — read as one word | leave |

## 3.4 Markdown & emojis — DELETE these before generating audio

These appear in the source `.md` files and will be read out as literal junk if pasted into TTS. Strip them completely:

- **Formatting:** `#` `##` `###` headers, `**bold**`, `*italics*`, `~~strikethrough~~`, `>` blockquotes, `|` table pipes, `---` horizontal rules, `` `backticks` ``, `-` / `*` bullet markers.
- **Citation brackets:** `[5, 691, 1302]`, `[52, 696]`, etc. — **these are the single biggest landmine.** Cartesia will literally read "five, six ninety-one, one thousand three hundred and two." Delete every square-bracket citation from the sales letter before it goes anywhere near audio.
- **Emojis / dingbats:** `🎬` `👉` `⭐` `⭐⭐⭐⭐⭐` `✓` `📍` `⚡` `🧠` `💬`. Strip them, or convert meaning to words (`⭐⭐⭐⭐⭐` → "five stars" only if you actually want it spoken).
- **Strikethrough prices** (`~~$550~~ $297`): TTS can't convey "crossed out." Rewrite as spoken contrast: *"normally five hundred and fifty dollars — right now, two hundred and ninety-seven."*

## 3.5 Words & abbreviations Cartesia may mispronounce

| Written | Safer for TTS |
|---|---|
| `HEPA` | write "hepa" or "high-powered vacuum" (avoided in this script on purpose) |
| `Dr.` | write "Doctor" |
| `Mr.` / `Mrs.` | write "Mister" / "Missus" |
| `e.g.` / `i.e.` / `etc.` | write "for example" / "that is" / "and so on" |
| `SMS` | usually fine as letters, but "text message" is safer |
| `Tri-Active` | reads as "try active" — correct; leave it |
| Initials like `Sarah & Mitchell K.` | write "and", drop the lone "K." or say the full surname |

5. On-screen text uses **Part 1** (figures look sharp); the voice speaks **Part 2** (fully normalised). They don't need to be word-identical — showing `$297` while the voice says "two hundred and ninety-seven dollars" is fine and reads cleaner on screen.
